# Moonlit Loops — Launch Draft with Real Product Photos

This is the India-first Moonlit Loops launch draft for **Moonlit Loops by Jyotsna**.

## What changed in this version
- Uses Jyotsna's real uploaded crochet photographs for homepage category cards.
- Uses a real Jyotsna photograph in the **Meet Jyotsna** section.
- Uses selected real photographs in matching shop cards where the product/category is reasonably represented.
- Keeps the original crochet work, colours and proportions intact; images are only cropped/lightly corrected for presentation.
- Keeps the existing India-first, made-to-order, INR, WhatsApp-ordering model.
- Keeps Digital Patterns and Crochet Coaching as Coming Soon.
- Keeps the WhatsApp number centralized in `src/config/siteConfig.ts`.

## Important
The six category cards are now based on real photos. The **Crochet for Pets** card intentionally remains a simple `REAL PET PHOTO / COMING SOON` placeholder because no pet-specific product photograph was available among the supplied images. This avoids showing a misleading image.

npm install
npm run build
