# Moonlit Loops by Jyotsna — Launch Draft

India-first handmade crochet website.

## Launch model
- Handmade crochet only
- Made to order by default
- Public INR pricing
- Cart → WhatsApp
- Manual payment after order confirmation
- India-only shipping at launch
- Digital patterns intentionally deferred
- Product photography can be added later

## Before public launch
1. Add Jyotsna's real WhatsApp number in `src/config/siteConfig.ts`.
2. Replace the photo placeholders with real product images.
3. Verify the product names, prices, colours, sizes and making times against the master spreadsheet.
4. Review the shipping/returns wording with the actual operating process.
5. Run `npm install` then `npm run build`.
